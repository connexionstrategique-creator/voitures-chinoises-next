```

```

**Cause :** la clé `ANTHROPIC_API_KEY` fournie dans les identifiants de la routine n'a plus de crédit. Le script utilise cette clé pour appeler `api.anthropic.com` directement (génération de contenu), indépendamment de la session Claude Code elle-même.

**Contournement appliqué aujourd'hui :** j'ai rédigé l'article moi-même (en respectant exactement le cahier des charges éditorial du script — structure, mots-clés, ton, FCFA, FAQ, images catalogue uniquement) et je l'ai publié directement dans Sanity via le connecteur MCP (`Create document(s)` + `publish_documents`), en sélectionnant les images via `query_documents` sur les fiches voitures (`_type=="car"`).

**Action requise côté utilisateur :** recharger le crédit du compte Anthropic associé à `ANTHROPIC_API_KEY` (Plans & Billing), sinon les prochaines exécutions automatisées (GitHub Actions quotidien à 6h UTC, et cette routine) échoueront de la même façon et nécessiteront à chaque fois une intervention manuelle de secours.
