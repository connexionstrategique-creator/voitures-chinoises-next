### Cause principale : crédit API Anthropic épuisé

L'appel à l'API Claude (`x-api-key` = `ANTHROPIC_API_KEY`) pour générer l'article de blog a échoué :

```
Anthropic API 400: {"type":"error","error":{"type":"invalid_request_error",
"message":"Your credit balance is too low to access the Anthropic API.
Please go to Plans & Billing to upgrade or purchase credits."}}
```

`scripts/seo-daily.mjs` s'arrête dès la première erreur fatale (try/catch global), donc ni l'article de blog ni l'optimisation des fiches voitures n'ont été traités.

**Action requise :** recharger le crédit sur le compte Anthropic (Plans & Billing) associé à la clé `ANTHROPIC_API_KEY` utilisée par ce script.

### Problème secondaire : accès direct à l'API Sanity bloqué par le proxy réseau

Avant même l'erreur Anthropic, la lecture des articles existants (pour éviter les doublons) a échoué :

```
⚠️ Lecture articles existants échouée (proxy) : tunneling socket could not be established, statusCode=403
```

Le proxy de sortie de cet environnement (agent-proxy) refuse les connexions directes vers `t3ow1rmc.api.sanity.io:443` (politique d'organisation, `connect_rejected` ×6 sur toute l'exécution). Cela signifie que **même une fois le crédit Anthropic rechargé**, les scripts `seo-blog.mjs` / `seo-cars.mjs` / `seo-links.mjs` ne pourront pas lire/écrire directement Sanity via `@sanity/client` + `SANITY_TOKEN` dans cet environnement — seul le connecteur MCP Sanity (déjà utilisé pour la publication finale) passe. Il faudra soit autoriser `*.api.sanity.io` dans la politique réseau de l'environnement, soit adapter les scripts pour ne faire aucun appel réseau direct à Sanity (tout passer par MCP).
