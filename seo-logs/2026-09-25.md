## ⚠️ Incident : échec de l'automatisation standard

`node scripts/seo-daily.mjs` a été lancé normalement, mais a échoué avant de pouvoir générer l'article :

```
Anthropic API 400: {"type":"error","error":{"type":"invalid_request_error",
"message":"Your credit balance is too low to access the Anthropic API.
Please go to Plans & Billing to upgrade or purchase credits."}}
```

**Cause :** la clé `ANTHROPIC_API_KEY` fournie dans `.env.local` a un **solde de crédit épuisé**. Ce n'est pas un problème de code — l'appel API échoue dès la première requête (`generateArticle()` dans `scripts/seo-blog.mjs`).

Par ailleurs, l'accès direct à l'API Sanity (`t3ow1rmc.api.sanity.io`) reste bloqué par la politique réseau du sandbox (`connect_rejected`), comme lors des exécutions précédentes — c'est le comportement attendu documenté dans `CLAUDE.md`, qui prévoit le repli sur le connecteur MCP Sanity.

**Action requise de votre part :** recharger le solde de crédit du compte Anthropic associé à cette clé API (Plans & Billing), sans quoi la routine automatisée `seo-daily.mjs` échouera de nouveau demain et les jours suivants.
